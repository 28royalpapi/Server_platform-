Privacy Notice

Server processes the phone number you register, authentication metadata, account preferences, call signalling events, guest invitation tokens, and short-lived SMS queue records needed to deliver verification texts and guest links.

OTP handling

Supabase Auth generates and validates verification codes. The Send SMS hook queues the code for the operator-controlled SIM gateway. The public web page does not receive the code from the backend. SMS bodies are cleared from the queue after the gateway reports a send, delivery, or failure result; job status and timestamps may remain for diagnostics.

Calls

Call signalling stores call setup messages such as offers, answers, and ICE candidates. Audio is intended to travel through WebRTC peer-to-peer when possible, or through a configured TURN relay when required; the signalling database is not an audio recording service.

Permissions and contacts

Web setup preferences do not grant operating-system permissions. Installed apps must separately ask for microphone, notifications, or contacts access. Contact access is optional.

Retention and controls

Early builds need production retention, deletion, access/export and support procedures before launch. Never share a verification code or guest invitation link with someone you do not trust.

Effective date: 21 October 2026. This draft requires legal review before public launch.
